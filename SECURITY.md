# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately to the project maintainer.

Do not publish sensitive exploit details or credentials in public issues.

## Credential Safety

- Never commit API keys or private keys.
- Never share wallet seed phrases.
- Use API permissions with the minimum required access.
- Disable withdrawal permissions where possible.
- Rotate credentials if they may have been exposed.

## Disclaimer

Users are responsible for securing their own systems, accounts, and credentials.
