# Contributing

Thank you for your interest in contributing to NovaQuant Sniper Bot.

## Before Contributing

- Review the project documentation.
- Keep changes focused and easy to review.
- Do not include credentials, private keys, or personal data.
- Do not claim support for integrations that have not been tested.

## Issues

When reporting a problem, include:

- A clear description of the issue
- Steps to reproduce it
- Relevant error messages
- The software version and environment

Never include secrets or account credentials in an issue.
